# Life OS

Пользовательская инструкция находится в [README в корне репозитория](../README.md).

Эта папка содержит исходный код приложения:

- `backend/` — локальный сервер и работа с данными;
- `frontend/` — интерфейс React;
- `ARCHITECTURE.md` — устройство приложения для разработки;
- `SPEC.md` — правила, которые важно сохранить при изменении кода.

## Карта проверяемых поверхностей

| Поверхность | Пользовательская цель | Граница данных |
| --- | --- | --- |
| `/ai-reviews` → «Покрытие и использование» | Проверить дизайн-review, использование экранов/функций/сценариев и здоровье allowlisted сигналов за выбранный закрытый период. | Только локальный allowlisted read model: повторные события сгруппированы по безопасной сигнатуре; без личного текста, идентификаторов сессий, entity/source paths и raw payload. Неполные источники, отсутствие события и отсутствие instrumentation не выдаются за продуктовый вывод или поломку. |
